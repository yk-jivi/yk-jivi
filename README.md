### 👩‍💻 О себе (About Me)

- 🎓 **Образование:** Студентка Белорусского государственного технологического университета (**БГТУ**), факультет информационных технологий (специальность *«Информационные системы и технологии»*).
- 💡 **Специализация:** Разработка современных веб-интерфейсов на **React** и проектирование производительных баз данных (**Oracle Database**, **PL/SQL**).
- 🎨 **Интересы:** Проектирование пользовательских интерфейсов в **Figma**, разработка дизайн-систем, оптимизация сложных SQL-запросов и построение отказоустойчивых баз данных.
- 🚀 **В процессе изучения:** Продвинутые паттерны React, архитектура микрофронтендов, глубокая оптимизация индексов и планов запросов в реляционных СУБД.
